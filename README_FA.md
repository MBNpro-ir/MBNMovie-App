# MBNMovie

برنامهٔ فیلم و سریال فارسی برای Android و Windows، بر پایهٔ رابط Flutter برنامهٔ MBNMovie.

طراحی، انیمیشن‌های جابه‌جایی، صفحهٔ خانه، دسته‌بندی، جست‌وجو، صفحهٔ جزئیات، پخش‌کننده و مدیریت دانلود از همان ساختار منتقل شده‌اند. محتوای فیلم و سریال از سرویس جدید با نشست مهمان خوانده می‌شود. بخش محتوای بزرگسال در رابط این نسخه وجود ندارد.

## اجرا

```sh
flutter pub get
flutter run
```

برای ساخت APK آزمایشی:

```sh
flutter build apk --debug --target-platform android-arm64
```

شناسهٔ Android: `com.mbn.movie`. فایل‌های دانلودشده در `Downloads/MBNMovie` نگهداری می‌شوند.

برخی قابلیت‌های حساب کاربری و به‌روزرسانی نسخهٔ قبلی به سرویس و مخزن قدیمی وابسته بودند و در این نسخه تا زمان پیاده‌سازی قرارداد متناظر فعال نیستند. پخش و دانلود به دسترسی لینک‌های سرور محتوا وابسته است.
